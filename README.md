### Introduction

This library contains classes for abstracting a Graphical User Interface.


### Why?

What started as an exercise is now a GUI toolset that can be added to any renderer or project.


### Library

Contained in this release is a series of classes that are used for supporting a GUI system.

The javadocs contain basic outlines of each package's contents.


### Compiling with Maven

To install/compile this library and make all artifacts with Apache Maven, type:

	mvn install

To compile this library, type:

	mvn compile

To make Maven-compatible JARs of this library, type:

	mvn jar:jar

To make Javadocs:

	mvn javadoc:javadoc

To run tests, type:

	mvn test

To generate a coverage report, type:

	mvn test jacoco:report

To clean up everything:

	mvn clean
